# plan-004 — 视觉与素材：少女歌剧主题化

- 日期：2026-10-26
- 前置：plan-003（全部模式可玩）

## 背景与目标

plan-002/003 交付功能完整但视觉是「暗色骨架」。本计划做少女歌剧主题化与视觉打磨：
- 主题色系：舞台帷幕红金 + 九九组角色色点缀（调研报告 §二：華恋红 #FB5458、ひかり蓝、まひる黄绿、純那水蓝、なな黄、クロディーヌ橙、真矢白、双葉紫、香子粉；hex 多数待查，先用色名近似值并集中定义在 CSS 变量便于校正）
- 视觉元素：封面卡片化（圆角+阴影+hover）、结算页逐题封面墙、题号进度条星光化、波形动画打磨
- 素材：官网立绘/视觉图 URL 已在调研报告 §三记录（revuestarlight.com/animation/character/ 等，JS 渲染需浏览器提取，**仅本地使用、遵守 NOTICE**）；logo 可用文字排版替代（「少女☆歌劇 レヴュースタァライト 猜歌」+星形装饰）
- 分享图：Canvas 生成成绩图（对齐 MyGO：成绩/模式/用时/二维码占位）；剪贴板文案分享
- 动效：过场淡入淡出、答题反馈动效、CSS only（不引动画库）

## 交付物清单（草案）

1. 主题 token：CSS 变量/ Tailwind 主题扩展（舞台红金 + 9 角色色）
2. 三页面 + 组件视觉打磨（封面墙、星光进度、波形）
3. 成绩分享：Canvas 图片生成 + 下载 + 剪贴板文案
4. （视素材可得性）官网视觉图接入；不可得则文字 logo 方案
5. 流程文档四件套

## 验收标准（草案）

- [ ] `npm test` 全绿、`npm run build` 成功
