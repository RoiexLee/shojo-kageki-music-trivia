# Plan 007：片段、中文歌词与同步混合猜歌

## 背景与目标

按最新玩法要求，将开头猜歌改为片段猜歌；歌词题直接展示中文翻译，揭晓答案后试听对应歌曲；混合连猜改为两首片段同时重叠的混合猜歌。

片段猜歌使用曲中配置的切片起点（沿用 `chorusStartSec`，缺省 72 秒），简单/普通/困难为 15/10/5 秒。歌词揭晓后播放正确歌曲的 10 秒片段（不宣称与题面那句歌词时间对齐）。混合模式所有难度固定两首不同歌曲，各 10 秒，真正同一时间开始、等增益叠加；4/6/8 选 2。

## 可验证交付物与涉及文件

- `apps/web/src/core/quiz.ts`、相关测试：新显示名称、中文歌词候选过滤（缺译/空译/标题泄漏排除）、固定双答案。
- `tools/prepare-audio/src/*`、相关测试、`packages/shared/src/types.ts`、`apps/web/src/data.ts` 及 fixtures：新增曲中 `clip-5/10/15` 切片与验证；保留旧切片兼容，生成物不入 Git。
- `apps/web/src/hooks/` 播放器及测试：以 Web Audio 解码并统一排程，单曲与双曲复用，音量按轨道数缩放；暂停/继续/重放/停止/手势恢复/加载失败提示与换题取消均覆盖。
- `apps/web/src/pages/HomePage.tsx`、`QuizPage.tsx`、页面测试、`App.tsx`（若需手势解锁）：中文题面作答前无音频，作答后正确歌曲试听；混合不再顺序播放。
- `apps/web/src/core/best.ts` 及测试：为规则变更的模式使用新版成绩键，保留旧记录但不把旧玩法成绩混作新纪录。
- `apps/web/index.html`、`README.md`、`plans/README.md`：同步实际玩法和资源生成说明；历史 plan 文档不改。
- 本目录完整计划/评阅/实现/实现评阅四件套与一次本地 main 提交。

## 实现步骤

1. 编排者检查 main、git log/status；研究 agent 只读核查中文覆盖和音频风险，独立 reviewer 写计划评阅。
2. PASS 后明确授权唯一 implementer 开始代码写入；修改纯规则与资源工具，生成新切片，修正验证器及数据 fixtures。
3. 实现同步 Web Audio 播放（先全部解码成功，再同一 `AudioContext.currentTime` 排程）；任一混合轨加载失败时整组停止并提供重试，不降级成单曲；异步结果以取消标识隔离。
4. 调整题面/状态生命周期：中文译文为主、揭晓可显示原文；答题前不可试听；答对或答错后均播放正确歌曲，下一题/退出停止。播放器状态变化不能意外重启音频。
5. 更新所有模式标签调用、复制/图片导出标签、提示和文档；旧 `intro` 模式标识可保留作为内部兼容键，不把旧显示文案保留下来。
6. 完成有意义单测：中文候选/标题与空译/真实曲库覆盖、三难度两首互异、同步时间与增益、慢加载/失败/手势/暂停恢复/换题取消、歌词播放时序。
7. `npm run assets`、`npm test`、`npm run build`、`npm run assets -- --verify`；当前版本桌面与 375px 浏览器验收三个新玩法，并以实际 Web Audio 调度/输出轨道证据核验重叠。
8. 编写实现纪要，reviewer 只读评阅；FIX 原 reviewer 复核 PASS 后，由编排者执行 `plan-007(web): 中文歌词揭晓试听与双曲混合猜歌`。

## 验收标准

- [ ] 首页/题页/结算/分享/说明显示“片段猜歌”“混合猜歌”，无旧玩法提示残留。
- [ ] 片段猜歌播放曲中片段，三难度 15/10/5 秒及 3/4/6 选项，生成资源校验通过。
- [ ] 歌词题作答前直接显示非空中文翻译，不显示日文原句、不播放音频；未翻译行不被抽入题面。
- [ ] 歌词答对/答错揭晓后均播放正确歌曲的 10 秒片段；播放器可暂停、继续、重听，下一题和退出无残留音频。
- [ ] 混合各难度恰好两首不同歌曲同步重叠 10 秒，必须全部选对才计分；无顺序间隔/“第几段”文案。
- [ ] 双曲同一音频时钟排程，增益避免简单相加过载；失败、手势限制和异步取消不造成只播一轨或旧题串音。
- [ ] 新旧规则成绩不混用，不删除旧 localStorage 数据。
- [ ] 全部测试、构建与资源验证通过；桌面与 375px 真实交互、无横向溢出、无新增控制台错误，截图与音频证据写入纪要。
- [ ] `music/` 不变，无新依赖、生成产物不入 Git，独立实现评阅 PASS 后提交。

## 风险与回滚

Web Audio 自动播放受浏览器手势限制，提供明确点击恢复；解码请求晚完成需检查取消标识，避免跨题播放。中文候选缺失必须给出可读错误，不回退日文冒充译文。曲中切片默认 72 秒，不保证每首都是真实副歌或题面歌词所在位置，在说明中明确。保留旧切片和成绩数据，回滚本提交并重建资源即可恢复旧玩法；禁止修改源 `music/`。
