# plan-016：统一歌曲描述的中日文与英文数字空格

## 背景与目标

歌曲元数据没有 `comment` 字段，页面使用 `description` 作为曲目说明和揭晓文案。当前部分描述在中文/日文与英文或数字相邻处缺少空格，例如 `TV动画`、`Growth舞台`、`正面Revue`。需要只修正歌曲描述文本，统一中英文、中数字、日英文、日数字之间的空格，不改歌曲 ID、标题、文件夹或音频资源。

## 交付物清单

- [ ] 审查 `packages/shared/src/songs.json` 的 121 条歌曲 `description`。
- [ ] 修正所有中文或日文字符与 ASCII 英文/数字直接相邻的描述文本。
- [ ] 保持 JSON 结构、歌曲数量、ID、folder、资源路径和其他元数据不变。
- [ ] 补充可重复执行的格式检查测试或断言，避免后续新增同类问题。
- [ ] 更新实现纪要与评阅记录，说明修改条目数和验证结果。

## 涉及文件

- `packages/shared/src/songs.json`
- `packages/shared/test/songs.test.ts`
- `plans/plan-016-description-spacing/`

## 实现步骤

1. 用正则审查描述字段中 CJK（日文假名/汉字）与 ASCII 英文数字的相邻位置，列出命中条目。
2. 仅在 `description` 字符串中补入一个半角空格，保留原有标点、大小写和文案内容。
3. 在 shared 测试中加入描述空格边界断言，素材缺失时不依赖 `music/`。
4. 运行 `npm test`、`npm run build` 和 `npm run assets -- --verify`。

## 验收标准

- [ ] 121 条歌曲全部通过描述空格检查。
- [ ] 没有修改歌曲 ID、标题、folder、歌词、音频或封面文件。
- [ ] 新增测试能捕获中日文与英文/数字直接相邻的描述。
- [ ] 测试、构建和资源校验通过。

## 风险与回滚

- 自动补空格只处理 CJK 与 ASCII 英文数字的边界，不改日文内部、英文内部或数字内部格式；如有语义特殊写法，逐条回滚该字段即可。
- 回滚只需恢复 `songs.json` 和测试文件，不触碰 `music/`。
